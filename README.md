# Calculadora

Uma calculadora simples, moderna e responsiva, feita com HTML, CSS e JavaScript puro.

## Como executar

Abra o arquivo `index.html` no navegador. Não precisa instalar dependências nem servidor.

## Recursos

- Adição, subtração, multiplicação e divisão
- Porcentagem e troca de sinal
- Entrada pelo teclado
- Separador decimal no padrão brasileiro
- Copiar resultado
- Layout adaptável para celular e computador

## Publicação no GitHub Pages

O projeto foi preparado para publicação pelo GitHub Pages usando a branch `main` e a pasta raiz (`/root`).
